# FlixPiP
**モニター一枚でもゲーム中に動画みたいよね**
## 概要
ゲーム中にオーバーレイとしてWEBを表示できます。
netflixやPrime videoなどのDRMコンテンツも再生できます
## 動作環境
- Windows10 64bit版以降 (.NET10以降を実行可能な環境)
- Webview2がインストールされているかつ、実行できること。
## 使い方
アプリを起動したら小窓でgoogleが立ち上がります。
- Ctrl + ↑ でFlixPiPにフォーカスがあたり
- 矢印キー で移動
- Alt + 矢印キー でウィンドウサイズの変更
- Shift + 矢印上下キー で透明度の変更
- Ctrl + ↓ で透明化とマウスすり抜けモード
- Ctrl + ← でgoogleを開く
- Ctrl + → でアプリの終了
